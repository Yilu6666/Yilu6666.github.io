HITACHI HIGH-TECH SINGAPORE · WORKFLOW DELIVERY

Invoice Processing Workflow

From incoming email to a review-ready invoice. An RPA-alternative workflow delivered for Hitachi High-Tech Singapore, with human review retained before financial submission.

  1. Monitor mailbox
  2. Extract PDF/MSG fields
  3. Save & verify
  4. Human review

The problem

Manual attachment downloads and file handling interrupt a routine finance workflow. A usable MVP also needs to run on a company PC without development tools.

My contribution

Translated user feedback into the workflow: monitor the mailbox, extract PDF/MSG fields, deduplicate, archive and validate files, and retain human review with recoverable retry. Iterated with users on deployment and first-run setup.

Engineering choices

Sender filtering, duplicate checks, verified archive copies and recoverable retry. Missing fields or ambiguous attachments stay visible for review; existing files are not silently overwritten.

Evidence & boundary

203 local tests passed. Clean-package checks covered parsing, duplicate handling and delivery recovery. Classic Outlook setup has been trialled on company PCs; full mailbox-to-destination acceptance is still in progress. No automatic e-Workflow submission.

Python · Outlook · PDF/MSG · Windows packaging

HITACHI HIGH-TECH SINGAPORE · PUBLIC PROCUREMENT

Public Procurement Monitoring Workflow

A monitoring workflow delivered for Hitachi High-Tech Singapore, with missed matches and delivery status made visible.

  1. Fetch listings
  2. Classify relevance
  3. Build digest
  4. Track delivery

The problem

Relevant opportunities were missed, while email filtering created a separate delivery problem. A report being generated did not mean the intended readers received it.

My contribution

Used stakeholder examples to refine matching and separate CCS/CCUS, carbon credits / Article 6 and robotic inspection. Connected HTML summaries and spreadsheet review outputs to a daily monitoring workflow.

Engineering choices

Keep fetching, classification and delivery status distinct. Add duplicate-send protection and recoverable Outlook drafts; stop blind retries when submission status is uncertain.

Evidence & boundary

A documented live run recovered both reported missed examples. Recipients confirmed a reviewed report arrived. Scheduled Windows Outlook delivery and recovery remain subject to company-environment validation.

Python · GeBIZ · Outlook drafts · Windows packaging
